# homebrew-zhao

[Homebrew](https://brew.sh) tap for [zhao](https://github.com/allenhori/zhao-cli), a free, offline, deterministic breaking-change gate for dbt.

```bash
brew install allenhori/zhao/zhao
```

Update with `brew upgrade zhao`. `Formula/zhao.rb` is generated and pushed automatically by zhao-cli's release workflow on every stable release; don't edit it by hand.
